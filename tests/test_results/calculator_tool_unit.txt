TEST: Bloxi Calculator Tool Integration with Registry
====================================================

Test file:
    tests/unit/test_calculator_tool.py

Purpose:
    Verify that the calculator can be registered with Bloxi's ToolRegistry
    and executed through the common tool interface.

Why we test this:
    Individual tools should be usable through a shared registry rather
    than requiring the Agent Core to know each tool's implementation.
    This allows Bloxi to add capabilities without embedding tool-specific
    logic into the Agent.

What is tested:
    - Calculator registration and tool-definition discovery.
    - Execution of arithmetic expressions through the registry.
    - Rejection of unsafe expressions.
    - Rejection of unexpected arguments.

Test type:
    Unit tests

Isolation:
    Uses the local calculator implementation and ToolRegistry.
    No LLM API or network connection is required.
