# Bloxi — Native LLM Tool Calling

## Purpose
Verify that Bloxi can process LLM-requested tool calls, execute registered tools, and return the model's final response.

## Why This Test Exists
Tool calling introduces a multi-step interaction between the LLM, the tool registry, and conversation state. Tests help prevent malformed requests, incorrect message ordering, and infinite tool-execution loops.

## Coverage
- Execute a tool and return the final LLM response.
- Handle invalid JSON tool arguments.
- Handle unknown tools.
- Enforce the maximum tool-call round limit.
- Preserve the existing response path when no tools are registered.
- Maintain correct message ordering for multiple tool calls.

## Test Type
Unit tests using a fake LLM. No live Groq API calls are required.

## Isolation
Tool-calling behavior is tested independently of external LLM services.

## Test Command
`python -m pytest tests/unit/test_agent_tools.py -v`
