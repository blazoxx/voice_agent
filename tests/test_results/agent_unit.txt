TEST: Agent Core Unit Test
==========================

Test file:
    tests/unit/test_agent.py

Purpose:
    Verify that Bloxi's Agent Core correctly combines the system prompt
    and conversation messages, calls the LLM provider, and returns a
    structured AgentResponse.

Why we test this:
    The Agent Core is the central logic layer of Bloxi. Testing it
    independently ensures that its own orchestration logic works without
    depending on a real LLM API.

What is tested:
    - System prompt is included in the LLM request.
    - User messages are passed correctly to the LLM provider.
    - The Agent invokes the LLM provider correctly.
    - The generated response is returned through AgentResponse.
    - The session ID is preserved.
    - No tool calls are reported when no tools are used.

Test isolation:
    A FakeLLM is used instead of the real Groq provider. This makes the
    test deterministic and ensures that failures can be attributed to
    Agent Core logic rather than network or API issues.
